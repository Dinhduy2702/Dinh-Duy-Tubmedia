1. Dong ung dung va nhan Ctrl+C neu npm.cmd run dev dang chay.
2. Giai nen file PATCH.
3. Chep toan bo noi dung ben trong thu muc patch vao project hien tai.
4. Chon Replace the files in the destination.
5. Khong can xoa thu muc tool va khong can npm install neu node_modules van con.
6. Chay lan luot:
   npm.cmd run typecheck
   npm.cmd run lint
   npm.cmd run test
   npm.cmd run test:integration
   npm.cmd run build
   npm.cmd run dev
7. Sau khi kiem thu xong, tao installer moi:
   npm.cmd run dist
