VIDEO STUDIO PRO - THU MUC TOOL PORTABLE
========================================

Dat cac file sau truc tiep trong thu muc nay:
- yt-dlp.exe
- ffmpeg.exe
- ffprobe.exe
- ffplay.exe
- aria2c.exe (khong bat buoc)

Che do source/dev:
- Ung dung tu dong uu tien thu muc <project>\tool.
- Nut "Sua chua tat ca" tai trang Cong cu se chi tai tool bi thieu/hong.
- Nut "Cap nhat tat ca" cap nhat yt-dlp, bo FFmpeg (ffmpeg/ffprobe/ffplay) va aria2c.

Che do installer:
- Tool co trong folder nay duoc dong goi vao resources\tool.
- Ban update moi duoc luu trong userData\tools\current de khong can quyen Administrator.

Khong doi ten cac file exe.
